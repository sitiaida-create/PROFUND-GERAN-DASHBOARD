# PROFUND — Dashboard Hebahan Geran

Dashboard interaktif untuk MASTERLIST HEBAHAN GERAN - PROFUND.

Data dibaca terus daripada Published CSV Google Sheet yang dikonfigurasi dalam `index.html`, supaya perubahan pada Google Sheet boleh dipaparkan semula tanpa mengubah kod dashboard.

## Kandungan
- Rumusan KPI
- Graf hebahan mengikut bulan
- Graf kategori dan penaja
- Analisis permohonan
- Senarai hebahan dengan carian/filter
- Tarikh tutup permohonan dan status
- Popup butiran geran

GitHub Pages dideploy melalui GitHub Actions.
